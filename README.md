### Project Title / Headline

🛒 BlinkIT Grocery Sales Analytics Dashboard

An interactive Power BI dashboard designed to analyze BlinkIT grocery sales performance, product categories, outlet characteristics, customer ratings, and sales trends. The dashboard enables users to explore business performance across item types, outlet sizes, outlet locations, and establishment years.

### Short Description / Purpose

The BlinkIT Grocery Sales Analytics Dashboard is an interactive business intelligence solution developed in Power BI to analyze grocery sales data and identify key patterns in product performance and outlet operations. It provides a consolidated view of sales, item quantity, customer ratings, item visibility, outlet characteristics, and category-level performance to support data-driven business decisions.

### Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Main platform used for dashboard development and interactive data visualization.
📂 Power Query – Used for data cleaning, transformation, and preparation.
🧠 DAX (Data Analysis Expressions) – Used to create calculated measures such as Total Sales, Average Sales, Average Rating, and Item Count.
🗃️ Data Modeling – Used to organize the BlinkIT grocery dataset and establish relationships/fields for interactive analysis.
📈 Data Visualization – Used charts, KPI cards, slicers, donut charts, bar charts, line charts, funnel charts, and tables.
📁 File Format – .pbix for Power BI development and dashboard sharing.
### Data Source

Source: BlinkIT Grocery Dataset

The dataset contains grocery retail information covering items, sales, outlet characteristics, item visibility, customer ratings, outlet location, outlet size, outlet type, and establishment year.

Key fields analyzed in the dashboard include:

Item Type
Item Fat Content
Item Visibility
Outlet Type
Outlet Size
Outlet Location Type
Outlet Establishment Year
Total Sales
Average Sales
Number of Items
Average Rating

The data is structured to support analysis of both product-level performance and outlet-level sales performance.

### Features / Highlights
• Business Problem

Grocery businesses generate large amounts of sales and product data across different outlets and product categories. However, analyzing raw data makes it difficult to quickly identify top-performing products, profitable outlet types, sales trends, and customer preferences.

Key questions such as:

Which product categories generate the highest sales?
Which outlet locations perform better?
How does outlet size affect sales?
Which outlet types contribute the most revenue?
How do item characteristics such as fat content influence sales?
How have sales changed over different establishment years?

can be difficult to answer efficiently using raw datasets.

• Goal of the Dashboard

The goal of the dashboard is to provide an interactive analytical view of BlinkIT's grocery sales performance that:

Enables users to monitor overall sales KPIs.
Compares sales across different item categories.
Analyzes outlet size, type, and location performance.
Identifies sales trends over outlet establishment years.
Allows users to filter and drill down into specific business segments.
Supports data-driven decisions related to product and outlet performance.

The donut chart analyzes sales based on Item Fat Content, allowing comparison between different product fat-content categories.

📌 Outlet Size Analysis – Donut Chart

Displays the distribution of sales across different Outlet Sizes, helping evaluate whether smaller, medium, or larger outlets generate greater sales.

The line chart tracks Total Sales based on Outlet Establishment Year, helping identify changes and trends in sales performance over time.

📌 Outlet Location Analysis – Funnel Chart

The funnel visual compares sales across different Outlet Location Types, providing insight into how location characteristics influence overall sales.

📌 Item Fat Content by Outlet Location – Clustered Bar Chart

This visualization compares sales across Item Fat Content and Outlet Location Type, helping understand the relationship between product characteristics and outlet location.
